# 📚 BiblioTEC - Library Management System

**BiblioTEC** is a library management and data analytics software developed for the **Projeto Integrador I** course (August – December 2023) as part of the **Big Data for Business** Higher Education Technology Program at **Fatec Ipiranga "Pastor Enéas Tognini"** (São Paulo, Brazil).

## 🎯 Overview & Objectives

BiblioTEC was designed to integrate library collections across the **Centro Paula Souza (CPS)** educational network—a public vocational and higher education institution in São Paulo—assisting staff in their daily operations.

Beyond operational control, the system aims to:
* **Support Data-Driven Decision Making:** Collect and structure loan data to generate actionable insights.
* **Encourage Student Engagement:** Help management design targeted strategies to increase library usage for study and research.
* **Clear Data Visualization:** Present key metrics in an intuitive format for quick interpretation.
