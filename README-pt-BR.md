# 📚 BiblioTEC - Sistema de Gerenciamento de Bibliotecas

O **BiblioTEC** é um software de gerenciamento de empréstimos de livros para bibliotecas, desenvolvido para a disciplina de **Projeto Integrador I** (agosto a dezembro de 2023), do curso de Big Data para Negócios da Fatec Ipiranga.

## 🎯 Tema e Objetivos

O BiblioTEC foi desenvolvido para integrar os acervos das bibliotecas do **Centro Paula Souza (CPS)** e auxiliar os funcionários das bibliotecas das ETECs e Fatecs na realização de suas tarefas diárias.

Além do controle operacional, o sistema tem como objetivo:
* **Apoiar a tomada de decisão:** Coletar e organizar dados de empréstimos e acervo para gerar direcionamentos estratégicos.
* **Incentivar a leitura e pesquisa:** Ajudar os gestores a criarem ações para estimular os estudantes a utilizarem a biblioteca ativamente.
* **Facilidade de interpretação:** Apresentar dados complexos de forma visual, intuitiva e acessível.

---

## 🏢 Segmento de Mercado

O **Centro Paula Souza (CPS)** é uma autarquia do Governo do Estado de São Paulo responsável pela administração das ETECs (Escolas Técnicas) e Fatecs (Faculdades de Tecnologia). O BiblioTEC foi modelado diretamente para atender às demandas e particularidades das bibliotecas dessas unidades de ensino.
